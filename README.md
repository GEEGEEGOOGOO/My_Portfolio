# Shashank Kumar — Orange Editorial Portfolio

helloMuller-inspired direction adapted for Shashank Kumar. It uses the orange/black/white editorial design language from the CSS snippet you shared.

## Includes

- React + Vite + Node
- Framer Motion animations
- Safe lucide-react icons
- shadcn-style accordion
- Interactive 3D hero object
- Large editorial project case-study rows
- Fully responsive layout

## Run

```powershell
Remove-Item -Recurse -Force node_modules, package-lock.json -ErrorAction SilentlyContinue
npm install
npm run dev
```

Open `http://localhost:5173`.
